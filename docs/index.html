Local AI Model Gateway

在 Windows 上用一个本地网关管理 OpenAI、WorkBuddy 和 Google AI Studio 模型与思考档位。Gemini 可在 DeepSeek Harness、WorkBuddy 和模型管理页使用。

支持的模型和接口

提供方初始模型
OpenAI 官方 APIGPT-6 Luna、GPT-6.2 Astra、GPT-6.2 Sol、GPT-6 Astra
WorkBuddyHy4、Hy3、DeepSeek V4.1 Flash、GLM-5.3 Flash
Google AI StudioGemini 4 Hydrogen（免费、付费）、Argon（付费）、Carbon（付费）

GPT-6.2 Sol 和 GPT-6.2 Astra 提供 low、medium、high、xhigh、max 五档思考，默认 medium。

Claude Code 使用 Anthropic Messages 兼容接口，DeepSeek Harness 和 WorkBuddy 使用 OpenAI 兼容接口。三端都连接到 127.0.0.1:8791。模型管理页可检查 OpenAI 新模型，勾选后同步，并一键重启客户端。

在 Windows 上部署

准备 Windows 10 或 11、Node.js 24.5 或更高版本，以及要使用的客户端。解压部署包后，在目录中运行以下命令。

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1
  1. 默认安装到 E:\AI-Tools，使用 -InstallRoot 可切换到其他盘。
  2. 在目标电脑按需授权 WorkBuddy 并配置 OpenAI 和 Google AI Studio API 密钥。
  3. 打开桌面入口 Model Manager - Local Gateway，验证已配置的模型。网关随当前 Windows 用户登录启动。

也可以把下载的 ZIP 交给 Codex，请它按包内 README 安装并验证。账号授权和 API 密钥在目标机录入。

常见问题

Claude Code 怎么使用 OpenAI 官方 API？

启动网关提供的 Claude Code 入口，输入 /model 选择模型。网关将 Claude Code 的 Messages 请求转换为 OpenAI Responses 请求，并转发该模型支持的思考档位。

怎么在 DeepSeek Harness 和 WorkBuddy 使用 Gemini 4？

在网关安装目录的 .env 填入 Google AI Studio 密钥。GEMINI_API_KEY 对应 Hydrogen 免费入口，GEMINI_PAID_API_KEY 对应 Hydrogen、Argon 和 Carbon 的付费入口。再在客户端模型列表里选择需要的入口。

能直接用 WorkBuddy 模型发起纯对话吗？

可以。在模型管理页选模型、思考档位和系统提示词。请求通过本地适配器发到 WorkBuddy 上游，使用自己的账号授权。服务可用性、规则及费用由供应方决定。

新模型会自动同步吗？

模型管理页列出可核对的 OpenAI 候选模型，用户勾选并应用后才同步到三端。
